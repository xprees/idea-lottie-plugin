Reports references in a dotLottie state machine (s/<id>.json opened from a .lottie file) that point nowhere:
  • inputs that don't exist, or have the wrong type for the guard or action using them (also $input references)
  • unknown states in initial, toState and stateName
  • animations, markers (segment), themes (SetTheme) and layers (layerName) the file doesn't contain
  • duplicate input names and unknown input types
